# Локальные фоны

Положите сюда свои JPG, PNG и MP4. В `config/backgrounds.json` укажите путь
от корня репозитория, например `assets/backgrounds/office.png` с типом
`image` или `assets/backgrounds/lights.mp4` с типом `video`. Для видео
подойдёт короткий бесшовный луп. Готовые цветовые пресеты работают сразу.
